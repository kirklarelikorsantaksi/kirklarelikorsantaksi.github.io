# Kırklareli Korsan Taksi

Kırklareli korsan taksi hattında havalimanı yolu uzundur. İstanbul Havalimanı Kırklareli merkezden 189 kilometre, yaklaşık 2 saat uzaklıktadır. Lüleburgaz'dan çıkan yolcu için mesafe 141 kilometreye, Vize'den çıkan için 128 kilometreye iner.

Lüleburgaz ve Babaeski'deki fabrikaların personeli, Dereköy Sınır Kapısı'ndan Bulgaristan'a geçecek yolcu ve yazın İğneada ile Kıyıköy'e inen tatilci hattı kullanır. Demirköy üzerinden Dupnisa Mağarası'na yarım günde gidilip dönülür.
